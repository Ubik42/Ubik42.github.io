# Ubik42.github.io

Lucas Shen's bilingual AI Tool Technical Artist portfolio, published through GitHub Pages.

## Stack

- React 19 + TypeScript + Vite
- Motion for React
- React Three Fiber + Three.js
- One adapted React Bits interaction

## Local development

```powershell
npm install
npm run dev
```

## Quality checks

```powershell
npm run typecheck
npm run lint
npm run build
```

GitHub Actions builds `dist/` and deploys it to GitHub Pages.
