# 求职展示主页架构

## 目标

将 `Ubik42.github.io` 从通用个人介绍页调整为求职展示总入口，主定位为 AI / 工具管线向 TA 与引擎工具开发。

## 信息来源

- `D:\cs\resume-shen-yuyan-editable`：最新岗位定位、经历、教育和技术能力。
- `D:\cs\AIToolTA_Portfolio`：重点作品集、DCC-first 工程状态、公开证据和视觉素材。
- `Ubik42/Ubik42`：GitHub Profile 展示层与公开渠道。
- ArtStation 公开项目：材质、DCC 工具、实时场景、Shader 和 Houdini 练习。

## 页面结构

1. 首屏：姓名、头像、AI 工具 TA 定位和 DCC / AI / 引擎能力关系。
2. 重点作品集：`ai-tool-ta-portfolio` 的五个核心模块、公开证据指标和仓库入口。
3. 求职方向：DCC 管线工具、AI 工作流系统、实时图形与引擎三类能力，以及经历和教育。
4. 关于我：补充个人方法、兴趣和协作方式。
5. 公开仓库：重点工程、MayaCraft、GitHub Profile、个人网站、简历和数字孪生项目。
6. ArtStation：本地化作品图片轮播，每张图片指向对应公开项目。
7. 公开渠道：GitHub、ArtStation、哔哩哔哩和小红书。

## 工程组织

- `src/data/showcase.ts`：重点案例、求职方向、公开仓库和 ArtStation 双语内容模型。
- `FlagshipPortfolio.tsx`：重点作品集展示。
- `CareerFocus.tsx`：岗位定位、能力支柱和经历时间线。
- `RepositoryGallery.tsx`：GitHub 工程与展示层索引。
- `ArtstationCarousel.tsx`：支持自动轮播、手动切换和减少动态偏好的作品轮播。
- `public/media/portfolio`：从公开作品集工程提取的展示素材。
- `public/media/artstation`：ArtStation 公开作品的本地展示素材。
