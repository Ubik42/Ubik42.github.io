# 作品集参考与内容架构重构

## 本轮目标

解决上一版首页的三个问题：公开仓库抢占主体、AI 工具内容不完整、ArtStation 单图轮播无法形成完整作品判断。

## 参考研究

本地接入两个持续更新的外部参考源：

- `emmabostian/developer-portfolios`：约 1600 个作品集链接和机器可读的 `feed.json`。
- `Evavic44/portfolio-ideas`：作品集截图、Live URL、源码仓库和技术栈对照表。

同时查看技术美术作品集的组织方式，重点关注 KirinByte、Martin Dahlin、PolyLeaf 和 Maciej Sojka。共同结论是：先展示真实工具与生产问题，再用源码作为证据；不把 GitHub 仓库列表本身当成作品。
