隐私政策

适用于 Google OAuth 应用"my gmail api"。更新日期：2026-11-21

用途

这是一个个人自用的本地工具，只供本站作者读取和整理自己的 Gmail 邮箱。它不面向公众，不提供给其他用户使用。

访问的数据

工具通过 Gmail API 读取作者本人邮箱中的邮件元数据（发件人、收件人、主题、时间、标签和已读状态），并按作者的指令管理自己的标签和过滤器。它不读取邮件正文，也不发送邮件。

数据存储与共享

读取的数据只保存在作者本人的电脑上，不上传到任何服务器，不与任何第三方共享，不用于广告、分析或模型训练。

撤销授权

可以随时在 Google 账号的第三方访问权限页面 撤销本应用的访问权限。

联系方式

通过 GitHub 联系作者。

Privacy Policy

For the Google OAuth app "my gmail api". Last updated: 2026-11-21

Purpose

This is a personal local tool used only by the author of this site to read and organize the author's own Gmail mailbox. It is not offered to the public or to any other users.

Data accessed

Through the Gmail API, the tool reads message metadata (sender, recipients, subject, date, labels and read state) from the author's own mailbox, and manages the author's own labels and filters on the author's instruction. It does not read message bodies and does not send mail.

Storage and sharing

Data is stored only on the author's own computer. It is not uploaded to any server, not shared with any third party, and not used for advertising, analytics or model training.

Revoking access

Access can be revoked at any time on the Google Account third-party access page.

Contact

Contact the author through GitHub.
