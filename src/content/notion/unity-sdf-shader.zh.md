# 0. SDF 原理

- 有符号距离函数（SDF）是一种用于描述形状的数学方法。它为每个点提供一个距离值，该值表示该点到形状表面的最短距离。具体来说：
    - 如果距离值为负，表示该点位于形状内部。
    - 如果距离值为正，表示该点位于形状外部。
    - 如果距离值为零，表示该点恰好位于形状表面上。
- 通过组合多个 SDF，可以创建复杂的形状。这种方法在计算机图形学中非常有用，尤其是在生成体积效果（如云、烟雾等）时，因为它允许动态改变形状而无需重新建模。

# **1. 属性定义**

着色器以定义可调整属性的部分开始：

- **_SDF**：一个 3D 纹理，表示云形状的有符号距离场。
- **_Noise**：一个 3D 纹理，用于为云密度添加噪声效果。
- **_Absorption**：控制云对光的吸收程度。
- **_AmbientDensity** 和 **_AmbientIntensity**：控制环境光对云的影响。
- **_LightIntensity**：影响云的整体亮度。

# **2. 顶点着色器 (`vert`)**

顶点着色器负责处理顶点数据：

- **输入**：接收顶点位置和 UV 坐标。
- **输出**：将顶点位置转换到世界空间和裁剪空间，为在片元着色器中使用做好准备。

![image.png](image%2061.png)

# **3. SDF 融合函数**

这些函数定义了几何形状以及如何组合它们：

- **`sdSphere()`** 在 SDF 中定义球形形状。
- **`sdBox()`** 在 SDF 中定义盒体形状。
- **`opSmoothUnion()`** 平滑地组合两个形状。
- **`opSmoothSubtraction()`** 通过从一个形状中减去另一个形状来创建复杂形状。

![image.png](image%2062.png)

# **4. 云密度计算**

- **`cloud()`** 根据位置计算云密度，并应用噪声来模拟云的外观。

![image.png](image%2063.png)

# **5. 主要片元着色器 (`frag`)**

这是渲染过程的核心部分：

- 使用光线步进技术对体积云内的点进行采样。
- 基于密度和光学深度计算光散射效果。
- 将环境光与散射光相结合，产生逼真的云颜色。

# **7 总结**

- 该着色器结合了多种高级技术：
    - **用于形状定义的 SDF**：使用有符号距离函数动态定义复杂的云形状。
    - **用于体积渲染的光线步进**：实现光线步进来模拟光与云内粒子的相互作用，从而实现逼真的体积渲染。
    - **可自定义参数**：提供可在 Unity 编辑器中调整的属性，用于微调云的外观和行为。
    - **光散射模型**：结合了考虑环境光和方向光源的散射模型，增强了渲染的真实感。
